# Web3 Wallet 知识库

> 撕开揉碎 Web3 钱包赛道的一切，让所有人都能读懂技术和产品。

## 这是什么

这是一个关于 Web3 钱包的系统性知识库，覆盖钱包产品的方方面面：历史演进、技术架构、产品设计、生态格局、竞争壁垒、用户洞察等。

目标是把复杂的钱包赛道拆解成可理解的模块，无论你是开发者、产品经理、投资人还是普通用户，都能从中获得有价值的认知。

## 各章节概览

### [01 历史与演进](./01-history/)
从 Bitcoin Core 到 MetaMask，从助记词到 MPC，钱包形态如何一步步走到今天。

### [02 技术架构](./02-architecture/)
密钥管理、签名方案、账户抽象、MPC/TSS、硬件安全模块——把底层技术讲透。

### [03 产品设计](./03-product-design/)
交互范式、Onboarding 流程、Gas 抽象、多链体验——好钱包的设计哲学。

### [04 生态版图](./04-ecosystem/)
钱包在 Web3 技术栈中的位置，与 DApp、DEX、Bridge、DID 的关系网络。

### [05 竞争格局](./05-competition/)
主流钱包对比、差异化策略、护城河来源、市场份额变迁。

### [06 用户研究](./06-users/)
用户画像、使用场景、痛点地图、留存与流失分析。

### [07 商业模式](./07-business/)
Swap 手续费、聚合器分润、B2B SDK、钱包即入口的变现逻辑。

### [08 安全模型](./08-security/)
攻击面分析、钓鱼防护、交易模拟、权限管理、供应链安全。

### [09 未来展望](./09-future/)
链抽象、意图驱动、AI Agent 钱包、无感钱包的终局猜想。

### [10 厂商剖析](./10-providers/)
具体公司的技术和业务架构：Privy、Turnkey、Fireblocks EW、Crossmint 四家钱包基础设施，以及 AllScale、Infini、Karsa 三家建在它们之上的稳定币应用。

## 如何使用
