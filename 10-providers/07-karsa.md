# Karsa 剖析：用 P2P 供给网络给新兴市场做美元账户

## 一句话总结

Karsa 的产品叫"全球美元账户"，但它真正的创新在供给侧——用一套经过验证的 P2P 稳定币交易商网络来解决新兴市场"用本地支付方式买到美元"这件事，用户全程感觉像在用银行。

## 基本档案

| 项目 | 信息 |
|---|---|
| 定位 | 面向新兴市场的稳定币新银行 / 全球美元账户 |
| 批次 | Y Combinator W25 |
| 目标市场 | 新兴市场 1 亿+ 人口，重点提及巴基斯坦、印度、尼日利亚、肯尼亚 |
| 核心产品 | 虚拟美国银行账户、稳定币储蓄、跨境收付、Visa 卡 |
| 覆盖 | 收发款 50+ 国家，付款覆盖 80+ 国家（不同来源口径略有差异） |
| 供给侧 | 经验证的 P2P 稳定币交易商网络 |
| 规模 | 未公开披露用户数与交易额 |

## 产品与商业架构

### 核心洞察：新兴市场的真实痛点不是"想要加密货币"

```
Karsa 服务的人群：
  巴基斯坦、印度、尼日利亚、肯尼亚等地的
  个人、自由职业者、小企业

他们的真实需求：
  ✅ 想要美元（本币贬值、通胀）
  ✅ 想收国际客户的付款
  ✅ 想在本地兑现
  ✅ 想在全球消费

他们的障碍：
  ❌ 开不了国际银行账户
  ❌ 传统汇款渠道费率高、到账慢
  ❌ 加密钱包太复杂（私钥、gas、链的概念）

Karsa 的定位：
  不卖"加密货币"，卖"美元账户"。
  稳定币只是后端实现。
```

这个定位和 [09-future/04-invisible-wallet](../09-future/04-invisible-wallet.md) 讲的"无感钱包"是同一个思路：**用户不需要知道有区块链**。

### 关键创新：P2P 供给网络

这是 Karsa 最值得研究的部分ï¼也是它和其它稳定币新银行的真正差别。

```
问题：巴基斯坦用户想用本地支付方式买美元稳定币。
      谁来提供稳定币，谁来收本地货币？

常规方案：
  接一个持牌的 on-ramp 服务商
  → 问题：很多新兴市场没有覆盖，或费率极高，
         或需要用户完成复杂 KYC

Karsa 的方案：
  从一个经过验证的 P2P 稳定币交易商网络路由供给
  → 买家的本地支付款项直接付给这些交易商
  → 交易商提供稳定币

用户看到的：
  一个像银行/换汇所的界面
  选择金额 → 按市场价买入美元稳定币
  完全不知道背后是 P2P 撮合
```

**为什么这个设计聪明**：

```
1. 供给侧的覆盖问题被外包给本地已有的流动性
   （P2P 交易商本来就在做这件事，只是体验很差）
2. 不需要在每个国家自己拿牌照和银行关系
3. 本地支付方式的适配由交易商完成
4. 定价靠竞争，接近市场价

风险也很明确：
  ⚠️ 交易商的信用风险（收了钱不给币）
  ⚠️ 交易商的资金来源合规性（AML 敞口）
  ⚠️ 流动性和价格的不稳定
  ⚠️ 监管上，"路由 P2P" 的法律性质在很多司法区不明确
```

Karsa 强调交易商是"经过验证的"（verified），说明它自己也清楚风险集中在这一层。

### 产品线

```
个人
  虚拟美国银行账户（收国际付款）
  稳定币储蓄（美元计价）
  多币种余额
  跨境收发款（50+ 国家）
  Visa 卡（全球消费）
  本地兑现（cash out）

企业
  企业账户
  全球付款（80+ 国家）
  企业卡
```

从 YC 上线时的"买入并储蓄稳定币"到现在的"虚拟美国银行账户 + 卡 + 企业账户",产品线扩张速度不慢。

### 值得注意的产品设计：虚拟美国银行账户

```
这是新兴市场用户最想要的单一功能。

为什么：
  自由职业者接美国客户的活，
  客户想用 ACH / wire 付款，
  但自由职业者没有美国银行账户
  → 只能走 PayPal（费率高）或 Wise（不一定覆盖）

Karsa 给一个虚拟美国账户号：
  客户按美国国内转账付款
        ↓
  资金进入 Karsa
        ↓
  转成美元稳定币记入用户余额
        ↓
  用户可以存着、花卡、或本地兑现

对用户来说：
  他"有了一个美国银行账户"
  稳定币这个词根本不需要出现
```

### 商业模式（推断）

```
收入来源：
  1. 买入稳定币的价差（P2P 撮合的 spread）
  2. 跨境付款手续费
  3. 卡消费的交换费分成
  4. 余额收益利差（如果有部署）
  5. 可能的企业账户订阅

早期宣传强调"免费/低费"的美元兑换，
说明现阶段是在用价格换增长，
真正的毛利可能主要靠卡和付款业务。
```

### 托管模型

```
公开信息不足以做确定判断，但从产品形态推断：

  虚拟美国银行账户 + 卡 + 即时兑现
  → 需要平台能实时调度资金
  → 高度可能是托管型账户 + 链上结算

有来源提到"通过智能合约提供托管服务（escrow）
和对资金的完全控制"，
这可能指的是 P2P 交易环节用智能合约做担保交易，
而不是用户余额是自托管的。

这一点必须在尽调时问清。
```

## 批判性分析

### 优势一：市场选择正确

```
新兴市场的美元需求是这个周期里最确定的稳定币用例。

对比其它稳定币场景：
  DeFi 交易       → 周期性强
  NFT / 游戏      → 已冷却
  企业跨境支付     → 销售周期长
  新兴市场储蓄美元 → 需求刚性、持续、规模大

Karsa 押的是最硬的那个需求。
```

### 优势二：供给侧创新有真实壁垒

```
接一个 on-ramp API 谁都会做。
建一个"经过验证的 P2P 交易商网络"需要：
  - 本地关系
  - 风控和验证流程
  - 争议处理机制
  - 长期声誉积累

这是一个会随时间加深的壁垒，
比"我们的 App 更好看"结实得多。
```

### 优势三：定位彻底去加密化

```
"虚拟美国银行账户"这个说法
比"稳定币钱包"好卖一百倍。

用户心智里：
  银行账户 = 熟悉、可信
  加密钱包 = 复杂、有风险

这个包装是对的。
```

### 局限一：规模上处于早期，赛道已经很挤

```
对照同赛道：
  KAST：$80M A 轮（2026.03），估值 $6 亿，
        100 万+ 用户，年化交易额约 $50 亿，
        目标 2026 年 $1 亿收入年化
  AllScale：$6.5M 种子，150 万钱包
  Karsa：YC W25，未披露融资和规模

新兴市场稳定币账户这条赛道已经有拿到大额融资、
规模跑出来的玩家。Karsa 需要证明它的
P2P 供给网络能带来对手复制不了的成本或覆盖优势。
```

### 局限二：P2P 供给的合规敞口是最大风险

```
这是最需要盯的一项。

风险场景：
  1. 某个"经过验证"的交易商的资金来源有问题
     → Karsa 成为洗钱通道的一环
  2. 目标市场的监管收紧
     （巴基斯坦、尼日利亚等地对加密的政策反复）
  3. 银行合作方发现资金来自 P2P 网络后切断关系
  4. 交易商跑路导致用户损失，责任归属不清

传统 on-ramp 服务商的价值就在于它承担了这些风险
（用牌照和合规成本换）。
Karsa 用 P2P 绕过了成本，也绕过了保护。
```

### 局限三：虚拟美国银行账户依赖上游合作方

```
Karsa 自己不是美国银行。
虚拟账户号必然来自某个 BaaS 合作方或持牌机构。

风险：
  ⚠️ 合作方切断服务 → 核心功能立刻失效
  ⚠️ 合作方的 KYC/AML 要求变严 → 用户被清退
  ⚠️ 加密相关业务被合作方视为高风险类别
     （历史上这种切断经常发生）

这是一个 Karsa 无法完全控制的单点。
```

### 局限四：信息披露太少

```
公开找不到的关键信息：
  ❓ 融资金额和投资方（YC 之外）
  ❓ 用户数、交易额、增长率
  ❓ 托管模型的准确描述
  ❓ 用户余额是否隔离
  ❓ 持有或依赖哪些牌照
  ❓ 底层钱包基础设施用的是谁
  ❓ P2P 交易商的验证标准和争议处理机制

对一个处理跨境资金的产品，这个披露水平偏低。
可能只是早期公司还没做这些内容，
但尽调时必须问到。
```

## 尽调必问清单

如果你要用 Karsa（或投它、或和它合作），这些是必须问清的：

```
托管与资产安全
  1. 用户余额是托管还是自托管？技术上谁能动？
  2. 用的是哪家钱包基础设施？
  3. 用户资金和运营资金是否隔离？有审计吗？

P2P 供给网络
  4. "经过验证"的具体标准是什么？
  5. 交易商违约时谁承担损失？
  6. 有没有智能合约担保？合约审计过吗？
  7. 交易商的资金来源如何做 AML 筛查？

牌照与合规
  8. 虚拟美国银行账户的持牌机构是谁？
  9. 各目标市场分别持有或依赖什么资质？
  10. 目标市场政策变化的应急方案是什么？

规模与财务
  11. 当前用户数、月交易额、留存率？
  12. 单位经济：每用户获客成本 vs 生命周期价值？
  13. 融资情况和跑道？
```

## 小结

Karsa 的判断力很好：**它选对了这个周期里最刚性的稳定币需求（新兴市场的美元储蓄和收款），也选对了包装方式（不叫钱包，叫美元账户）。** 更重要的是它在供给侧做了真创新——用 P2P 交易商网络解决"本地支付方式买美元"这个别人绕不过去的问题ï¼而这个网络是会随时间变深的壁垒。

它的风险几乎全部集中在同一个地方：**P2P 供给网络既是它的护城河ï¼也是它最大的合规敞口。** 传统 on-ramp 服务商用牌照和合规成本换来的保护ï¼Karsa 用 P2P 绕过了成本ï¼同时也失去了保护。再加上虚拟美国账户依赖上游持牌合作方ï¼它有两个自己控制不了的单点。

从赛道看ï¼它现在的处境不轻松——KAST 这类对手已经拿到 $80M 融资和百万级用户ï¼新兴市场美元账户已经不是一个空白市场。Karsa 要赢ï¼得证明 P2P 供给网络带来的覆盖或成本优势ï¼是钱买不到的。

由于公开信息有限ï¼本篇的结论比其它几篇更需要保留。真要判断这家公司ï¼前面那份尽调清单比任何外部分析都有用。
