# 无障碍设计与国际化

## 一句话总结

加密用户分布在全球各地、跨越各种语言和能力背景——好的钱包必须能服务残障用户、非英语用户、低带宽用户。

## 国际化（i18n）

### 语言覆盖优先级

```
Tier 1（必须支持）：
- 英语（全球通用）
- 中文简体（中国大陆 + 海外华人）
- 日语（高 ARPU 市场）
- 韩语（活跃加密市场）

Tier 2（重要）：
- 西班牙语（拉美 + 西班牙）
- 葡萄牙语（巴西）
- 越南语（东南亚）
- 印尼语（东南亚）
- 俄语（CIS 地区）
- 土耳其语（中东 + 高通胀市场）

Tier 3（增长市场）：
- 阿拉伯语（中东，注意 RTL 布局）
- 印地语（印度）
- 泰语
- 法语
- 德语
```

### 本地化不只是翻译

```
真正的本地化需要：

1. 数字格式
   - 英语：1,234.56
   - 德语：1.234,56
   - 印度：1,23,456

2. 日期格式
   - 美国：MM/DD/YYYY
   - 欧洲：DD/MM/YYYY
   - 日本：YYYY/MM/DD

3. 货币表示
   - 不同地区用户的法币基准不同
   - $1,000 vs €1,000 vs ¥1,000

4. 文化适配
   - 颜色含义（红色在中国是吉利，西方是危险）
   - 图标含义（手势在不同文化中含义不同）
   - 节日和营销活动

5. 法律合规
   - 不同地区的金融监管不同
   - 某些功能在某些地区可能违法
   - 隐私政策本地化
```

### RTL（右到左）布局

```
阿拉伯语、希伯来语等是从右到左阅读：

布局调整：
- 文本对齐：从左对齐改为右对齐
- 图标位置：左侧图标移到右侧
- 进度条方向：从左到右改为从右到左
- 箭头方向：← 变成 →
- 数字仍然是从左到右（这是个特例）

技术实现：
- CSS：dir="rtl" + 逻辑属性（margin-inline-start 而非 margin-left）
- 资源准备：图标可能需要镜像版本
```

## 无障碍设计（a11y）

### WCAG 标准

```
Web Content Accessibility Guidelines (WCAG) 2.1：

A 级（最低）：
- 图片有替代文本
- 视频有字幕
- 颜色不是唯一信息来源

AA 级（推荐）：
- 文本对比度 ≥ 4.5:1
- 可以仅用键盘操作
- 焦点可见
- 错误识别和建议

AAA 级（理想）：
- 文本对比度 ≥ 7:1
- 手语翻译
- 阅读级别适合中学水平
```

### 钱包的 a11y 要点

```
1. 屏幕阅读器支持
   - 所有按钮有 aria-label
   - 表单元素有正确的 label
   - 动态内容有 aria-live 提示
   - 关键操作有清晰的语义结构

2. 键盘导航
   - 所有功能可通过键盘访问
   - Tab 键顺序合理
   - 焦点状态清晰可见
   - 快捷键支持（如 Cmd+K 搜索）

3. 视觉辅助
   - 文字大小可调节
   - 高对比度模式
   - 减少动画选项（避免眩晕）
   - 不依赖颜色传达信息（如交易状态用图标 + 文字）

4. 触摸目标
   - 移动端按钮 ≥ 44×44 像素
   - 间距足够避免误触
```

### 加密领域的特殊挑战

```
1. 助记词输入
   - 屏幕阅读器读出助记词有泄露风险
   - 解决：提供"安全模式"，输入时屏幕阅读器只读"已输入第 N 个词"

2. 地址显示
   - 长地址对屏幕阅读器是噩梦（"零 x 七一 c 七..."）
   - 解决：提供 "0x71C7..976F" 的简化朗读 + 可选完整朗读

3. 数字精度
   - 加密金额可能是 0.000123456789
   - 屏幕阅读器读这种数字很慢
   - 解决：智能省略（"约 0.0001"+ 可选完整精度）

4. 二维码
   - 视障用户无法看二维码
   - 解决：必须提供文本替代（地址/URI 直接显示和复制）
```

## 低带宽 / 弱网络支持

### 新兴市场的现实

```
用户场景：
- 印尼用户用 3G 网络
- 非洲用户偶尔断网
- 拉美用户的 4G 信号不稳定
- 中国部分地区的网络限制

对钱包的要求：
- 离线可查看缓存数据
- 弱网下不阻塞 UI
- 数据传输尽量小
- 失败重试和优雅降级
```

### 优化策略

```
1. 数据传输优化
   - 用 GraphQL 减少冗余字段
   - 增量更新（只传变化的部分）
   - 压缩（gzip/brotli）
   - 图片懒加载和缩放

2. 缓存策略
   - 资产数据本地缓存
   - 已知合约 ABI 离线存储
   - 代币元数据持久化

3. 离线功能
   - 查看余额（用缓存数据）
   - 准备交易（签名后稍后广播）
   - 查看历史记录

4. 网络感知
   - 检测网络速度
   - 弱网下减少自动刷新频率
   - 提示用户网络问题
```

## 低端设备支持

```
现实：很多新兴市场用户用 $100 以下的 Android 手机
- RAM 1-2 GB
- 处理器较弱
- 存储有限

优化方向：
- App 大小控制（尽量 < 30 MB）
- 启动速度快（< 2 秒）
- 内存占用低
- 不依赖最新的 API
- 测试在低端设备上的表现
```

## 小结

无障碍和国际化不是"锦上添花"，而是钱包能否真正服务全球用户的基础。每多支持一个语言、一个能力背景、一种网络环境，钱包就多覆盖了一批潜在用户。

特别是对于"下一个 10 亿用户"的目标——他们大概率不在英语国家、不用旗舰手机、不在高速网络环境下。钱包产品如果要触达他们，就必须在这些维度上做好基础工作。
