# 留存与活跃度：钱包的北极星指标是什么

## 一句话总结

钱包不像社交产品有清晰的"日活"指标——什么算活跃、什么算留存，本身就是一个产品定义问题。

## 选择北极星指标的难点

### 钱包的特殊性

```
传统 App：每天打开就算活跃
钱包：用户可能每月只打开一次（HODLer）

但 HODLer 的钱包仍然有价值：
- 存了大额资产
- 长期信任
- 偶尔操作（市场波动时）

所以"日活"对钱包不一定是好指标
```

### 不同指标的偏重

```
1. 日活/月活（DAU/MAU）
   优点：通用，便于对比
   缺点：不反映价值（活跃 1 美元用户 = 活跃 100 万美元用户？）

2. 总管理资产（TVL/AUM）
   优点：反映用户信任和价值
   缺点：受市场波动影响大

3. 交易笔数
   优点：反映用户参与
   缺点：垃圾交易（如机器人）干扰

4. 交易额
   优点：反映商业价值
   缺点：与 Swap 收入相关，但用户可能去外部 DEX

5. 收入
   优点：商业指标
   缺点：可能与用户价值不一致（高费用伤用户）
```

## 钱包的合适指标

### 综合指标体系

```
顶层指标（北极星）：
"管理价值×活跃度"
即：用户在钱包中持有的资产价值 × 主动操作频率

分解：
1. 月活跃地址数（MAU）
2. 平均地址持有金额
3. 月交易笔数
4. 月交易额
5. 钱包内 Swap 量
```

### 不同钱包应该看不同指标

```
消费级钱包（MetaMask、Phantom）：
- DAU/MAU
- Swap 交易量（直接收入）
- DApp 连接次数

工具钱包（Rabby）：
- 活跃地址数（专业用户）
- 平均交易复杂度
- 安全事件拦截数（差异化指标）

机构钱包（Safe）：
- 管理资产（AUM）
- 多签操作数
- 集成 DApp 数量

嵌入式钱包（Privy）：
- 月活跃用户（DApp 整体）
- API 调用次数
- 集成 DApp 数量
```

## 留存曲线分析

### 典型钱包的留存

```
普通钱包：
D1: 50%
D7: 30%
D30: 15%
D90: 8%
D180: 5%

优秀钱包：
D1: 70%
D7: 50%
D30: 30%
D90: 20%
D180: 15%

对比 Web2 应用：
- 社交 App：D30 通常 20-40%
- 工具 App：D30 通常 10-30%
- 钱包介于中间，但波动更大
```

### 留存的关键节点

```
D1（次日留存）：
- 决定因素：Onboarding 体验、首次操作
- 关键问题：用户是否完成了"有意义的事"

D7（一周留存）：
- 决定因素：是否有持续使用的理由
- 关键问题：用户是否回来了第二次

D30（月留存）：
- 决定因素：钱包是否成为用户日常工具
- 关键问题：用户是否养成习惯

D90（季留存）：
- 决定因素：长期价值
- 关键问题：用户是否继续信任
```

## 流失原因分析

### 流失的主要原因

```
1. 没有持续的使用动机（30%）
   - 创建钱包后不知道做什么
   - 加密市场冷却

2. 体验问题（20%）
   - Gas 费太高
   - 操作复杂
   - 应用 Bug

3. 安全损失（15%）
   - 被钓鱼
   - 操作错误
   - 失去信任

4. 切换到其他钱包（15%）
   - 找到更好的替代
   - 朋友推荐

5. 资产太少（10%）
   - 没钱玩
   - 觉得不值得继续

6. 监管 / 地区限制（5%）

7. 其他（5%）
```

### 流失的早期预警信号

```
如果用户出现以下行为，流失风险增加：

- 7 天内未打开应用
- 30 天内零交易
- DApp 连接失败后未重试
- 反复添加和删除代币
- 搜索过"撤销授权"等关键词（可能被钓鱼）
- 客服咨询历史
```

## 提升留存的策略

### 策略一：建立使用习惯

```
- 每日签到（虽然简单但有效）
- 价格提醒（资产关注）
- 收益提醒（DeFi 头寸）
- 治理通知（DAO 参与）
- 社区活动（NFT、空投）

目标：让用户有"每天看一眼"的理由
```

### 策略二：提供持续价值

```
- 收益机会推荐（合规前提下）
- 新协议发现
- 风险提示和保护
- 性能优化（更快、更便宜）
- 新功能持续推出

目标：用户感受到"用这个钱包对我有持续的好处"
```

### 策略三：减少流失触发

```
- 防止用户被钓鱼（最重要）
- 防止用户操作失败
- 防止用户费用过高
- 防止用户找不到帮助

每次"糟糕体验"都是潜在的流失风险
```

### 策略四：召回机制

```
对流失用户：
- 邮件/推送提醒（有新功能、有空投资格）
- 重新引导（"上次你没完成 X，要不要继续"）
- 激励（回归奖励）

但不要骚扰：
- 不要垃圾邮件
- 给用户取消订阅的选项
- 推送频率控制
```

## 不同用户群体的留存

```
DeFi Degen：
- 高频活跃，但容易流失到更好的工具
- 留存依赖于：功能深度 + 安全性

HODLer：
- 低频但稳定，几乎不流失
- 留存依赖于：信任 + 偶尔的价值确认

NFT 收藏者：
- 受市场情绪影响大
- 牛市活跃，熊市流失
- 留存依赖于：市场恢复 + 社区

新用户：
- 流失率最高（D7 < 30%）
- 留存依赖于：Onboarding 后的引导

机构用户：
- 留存最稳定（年留存 > 80%）
- 留存依赖于：稳定 + 服务
```

## 分群分析的重要性

```
不要用一个数字代表整体：

错误：
"我们的 D30 留存是 15%"

正确：
"新用户 D30 留存 8%
 转化为活跃用户的 D30 留存 45%
 DeFi 用户 D30 留存 60%
 HODLer D30 留存 80%（即使他们不交易）"

只有分群分析才能发现真正的问题和机会
```

## 小结

钱包产品的留存指标比 Web2 产品更复杂，因为用户使用模式差异大。建立合适的指标体系需要：

1. **多维度指标**：不是单一 DAU/MAU
2. **分群分析**：不同用户群体看不同指标
3. **关注价值**：管理资产 + 活跃度 > 单纯活跃度
4. **理解周期**：加密市场周期影响巨大

最终的目标不是让所有用户每天都打开钱包（不现实），而是让钱包成为用户在需要时的首选——这种"心智份额"比"使用频率"更有价值。
