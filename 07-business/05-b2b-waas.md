# B2B WaaS（Wallet as a Service）：SDK 与 API 收费

## 一句话总结

WaaS 是钱包行业最被低估的赛道——不直接面向用户，但通过为开发者提供基础设施，赚取比消费级钱包更稳定、更可预测的收入。

## 商业模式

### 核心逻辑

```
WaaS 服务对象：DApp 开发者
WaaS 提供的：钱包基础能力（创建、签名、管理）
WaaS 收费方式：按使用量或订阅

类比：
- AWS：基础设施 + 按量付费
- Stripe：支付能力 + 抽成
- Twilio：通信能力 + 按调用付费
- WaaS：钱包能力 + 按 MAU/调用付费
```

### 主要定价模式

```
模式 A：按 MAU（月活跃用户）
- 每 MAU $0.01-$0.10
- 适合消费级 DApp

模式 B：按 API 调用
- 每千次签名 $X
- 适合特定操作场景

模式 C：固定订阅
- 月费/年费
- 包含一定额度
- 超出按量计费

模式 D：按 AUM
- 管理资产的百分比
- 主要用于机构服务

模式 E：定制企业方案
- 按合同
- 通常 $10K-$1M+/年
```

## 商业模式优势

### 1. 收入稳定可预测

```
对比消费级钱包：
- 消费级：随市场波动（牛熊差距 5-10 倍）
- WaaS：订阅 + 使用量，相对稳定

数据：
- WaaS 公司 NRR（净留存率）通常 > 100%
- 客户流失率低（< 10%/年）
```

### 2. 客户粘性极高

```
DApp 集成 WaaS 后：
- 切换需要重新开发
- 用户数据迁移困难
- 测试和验证成本高

迁移率：< 5%/年
LTV/CAC ratio：通常 > 3
```

### 3. 高利润率

```
软件即服务的特点：
- 边际成本低
- 规模效应明显
- 毛利率：70-90%

vs 消费级钱包：
- 需要大量营销投入
- 用户获取成本高
- 毛利率可能更低
```

### 4. 监管套利

```
WaaS 公司的监管优势：
- 不直接服务最终用户
- 责任分担给 DApp
- 监管要求相对低
- 国际化容易

vs 消费级钱包：
- 直接面对用户
- 完全承担合规责任
- 各国监管不同
```

## 商业模式劣势

### 1. 销售周期长

```
B2B 销售：
- 评估期：1-6 个月
- 集成期：1-3 个月
- 上线期：1-3 个月
- 总计：3-12 个月

vs 消费级：
- 用户 Onboarding：分钟级
- 病毒传播：自然
- 增长曲线：陡峭
```

### 2. 客户开发成本高

```
B2B 销售需要：
- 销售团队
- 解决方案工程师
- 客户成功团队
- 法务和合规

vs 消费级：
- 主要靠产品和营销
- 团队结构简单
```

### 3. 定制化压力

```
大客户经常要求：
- 特定功能开发
- SLA 保证
- 专属支持
- 定制合同

这会分散研发资源
```

### 4. 技术依赖风险

```
如果 WaaS 公司出问题：
- 大量 DApp 受影响
- 责任放大
- 信任难恢复

vs 消费级：
- 影响范围相对可控
```

## 主要竞争维度

```
1. 集成简单度

   - 示例代码

2. 用户体验

   - 签名体验
   - 跨设备同步
   - 恢复机制

3. 技术能力
   - 多链支持

   - 安全性
   - 可定制性

4. 商业条款
   - 价格
   - 灵活性
   - SLA
   - 支持质量

5. 合规和信任
   - 安全审计
   - 行业认证
   - 客户案例
   - 团队背景
```

## 给从业者的启示

### 创业者

```
WaaS 是好的创业方向，但门槛高：

技术门槛：
- 密码学专业知识（MPC、AA）
- 工程能力（SDK、API、稳定性）
- 安全意识（一次事故就完蛋）

商业门槛：
- B2B 销售能力
- 长期投入能力
- 合规和法律支持

成功要素：
- 找到差异化（细分市场或新技术）
- 建立信任（开源、审计、案例）
- 持续投入
```

### 投资人

```
WaaS 公司估值参考：

收入倍数：
- 高增长 SaaS：10-30x ARR
- WaaS 因为加密属性可能波动大

关键指标：
- ARR（年度经常性收入）
- NRR（净留存率）
- CAC（客户获取成本）
- LTV（客户生命周期价值）

风险点：
- 加密市场周期
- 监管不确定性
- 大客户集中风险
```

### DApp 开发者

```
选择 WaaS 的考量：

短期：
- 集成简单度
- 用户体验
- 价格

长期：
- 公司稳定性
- 数据迁移可能性
- 技术延展性
- 监管合规
```

## 小结

WaaS 是钱包行业的"卖铲子"——不直接做钱包给用户用，而是把钱包能力打包成服务卖给开发者。

它的特点：
1. 商业模式好（稳定、高粘性、高利润）
2. 但门槛高（技术 + 商业）
3. 长期看是赢家（基础设施层）

未来 5 年，WaaS 公司可能成为钱包赛道最大的赢家——比消费级钱包公司更稳定、更值钱。但要做好 WaaS 需要不同于消费级钱包的能力组合，不是所有团队都能切换过去。
