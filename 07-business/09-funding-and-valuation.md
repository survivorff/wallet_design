# 融资与估值：钱包项目的资本故事

## 一句话总结

钱包项目的估值在过去 5 年经历了从"基础设施溢价"到"现金流验证"的变化——理解资本市场如何看待钱包，能帮助我们更好地评估行业未来。

## 主要钱包公司的融资历史

### MetaMask / ConsenSys

```
ConsenSys（MetaMask 母公司）：
- 2014 年成立
- 2018 年：估值 $1B
- 2021.04：D 轮 $65M（估值 ~$3B）
- 2021.11：E 轮 $200M（估值 $7B）
- 2022.03：估值 $7B（验证）
- 2024：估值波动，市场冷静

MetaMask 单独估值（推测）：
- 占 ConsenSys 价值的大部分
- 估计单独估值 $3-5B
```

### Phantom

```
- 2021.07：种子轮 $9M（估值约 $50M）
- 2022.01：A 轮 $109M，估值 $1.2B（独角兽）
- 投资人：Paradigm、a16z、Variant、Jump
- 2024：保持独角兽估值，未公开新一轮
```

### Coinbase Wallet

```
作为 Coinbase 的一部分：
- Coinbase 是上市公司（COIN）
- 市值波动 $5B-$80B
- Wallet 业务未单独披露估值
```

### Trust Wallet

```
- 2018：被 Binance 收购，金额未公开
- 估计当时估值 $2-5M
- 现在作为 Binance 生态的一部分
- 作为独立产品估值难以估算
```

### Rabby / DeBank

```

  - 2021.04：A 轮 $25M
```

## 估值的逻辑

### 钱包公司怎么估值

```
传统 SaaS 估值方法：
- 基于 ARR（年度经常性收入）
- 倍数：5-30x（高增长）

钱包公司的特殊性：
- 收入构成复杂（Swap 费用、订阅、企业服务）
- 收入受加密市场周期影响
- 用户价值难以量化

主要参考指标：
1. 月活跃用户（MAU）
2. 总管理资产（TVL/AUM）
3. 月交易量
4. ARR（实际经常性收入）
5. 增长率
```

### 不同类型钱包的估值逻辑

```
消费级钱包（MetaMask、Phantom）：
- 主要看用户量
- 每 MAU 估值：$50-500
- 牛市高，熊市低

WaaS 公司（Privy、Dynamic）：
- 主要看 ARR
- 倍数：10-30x
- 类似 SaaS 估值

机构钱包（Fireblocks）：
- 主要看 AUM 和 ARR
- 倍数：15-25x ARR
- 受机构客户数量影响

硬件钱包（Ledger）：
- 主要看销售量和重复购买
- 倍数：3-8x 收入
- 类似硬件公司
```

## 资本市场的态度变化

### 2017-2018：早期积累

```
特点：
- 加密刚被 VC 关注
- 钱包不是热门赛道
- 估值相对低（百万到千万级）
- 主要由加密 Native VC 投资

代表：
- ConsenSys 早期融资
- Ledger 早期融资
```

### 2020-2021：DeFi/NFT 牛市

```
特点：
- 钱包成为基础设施热门
- 估值飙升（独角兽频出）
- 顶级 VC 进入（a16z、Paradigm、Sequoia）
- "下一代基础设施"叙事

主要事件：
- Phantom $1.2B 独角兽
- ConsenSys $7B
- Fireblocks $8B
- 多个钱包项目融到 $50M+

逻辑：
"钱包是 Web3 入口，必将巨大"
"用户增长 = 价值增长"
```

### 2022-2023：熊市冷静

```
特点：
- 估值下调
- 一些项目融资困难
- 注重商业化和盈利
- "现金流为王"

主要事件：
- 多个钱包公司裁员
- 估值缩水 30-50%
- 但优质项目仍能融资

逻辑：
"用户量不够，要看收入"
"商业模式必须清晰"
```

### 2024-2025：选择性回暖

```
特点：
- 头部项目估值恢复
- 二线项目仍然困难
- AI 集成成为新故事
- 嵌入式钱包是新热点

主要事件：
- Privy、Dynamic 等 WaaS 持续融资
- AA 钱包项目获得关注
- 部分项目转向代币融资

逻辑：
"基础设施 + AI = 新机会"
"嵌入式钱包是下一个 1B 用户的入口"
```

## 不同融资策略

### 策略一：传统 VC 融资

```
适合：
- 服务美国市场
- 不想涉及代币复杂性
- 长期愿景的项目

代表：
- MetaMask（ConsenSys）
- Phantom
- Privy

优势：
- 没有代币监管压力
- 长期主义
- 类似传统科技公司路径
```

### 策略二：代币融资

```
适合：
- 服务全球市场
- 有清晰的代币用途
- 想要快速激励社区

代表：
- 1inch
- Trust Wallet（被收购前）
- 各种 DeFi 钱包

优势：
- 融资速度快
- 社区激励
- 流动性立即获得

劣势：
- 监管风险
- 代币价格压力
```

### 策略三：混合策略

```
代表：Safe
- 早期 VC 融资
- 后期发行代币
- 同时有股权和代币结构

平衡两种模式的优劣势
```

### 策略四：自给自足

```
一些钱包不接受外部融资：
- Rabby（DeBank 子产品）
- 一些小型钱包

依靠收入支撑：
- 增长慢但稳健
- 不受投资人压力
- 但难以快速扩张
```

## 估值的挑战

### 加密市场周期

```
钱包估值受加密市场情绪强烈影响：
- 牛市：估值飙升 5-10 倍
- 熊市：估值缩水 30-70%

很难判断"真实价值"
```

### 收入波动

```
钱包收入主要来自交易：
- 牛市交易活跃，收入暴涨
- 熊市交易冷清，收入暴跌

按"年度峰值"还是"低谷期"估值？
不同时点估值差异巨大
```

### 用户价值不一致

```
1 个 DeFi 重度用户 ≠ 1 个 HODLer
1 个机构客户 ≠ 100 个个人用户

简单的 MAU 数字误导
需要质量加权的指标
```

## 退出路径

### IPO

```
钱包公司上市的可能性：
- Coinbase 已上市（COIN）
- Ledger 多次传言但未实施
- 其他公司离 IPO 还远

挑战：
- 加密公司上市受监管影响
- 业务波动大
- 需要稳定的盈利
```

### 收购

```
常见收购：
- 大公司收购小钱包公司
- 例：Binance 收购 Trust Wallet
- 例：ConsenSys 收购多个工具

未来可能：
- Coinbase、OKX 等收购钱包公司
- 传统金融公司进入加密领域
- AI 公司收购钱包基础设施
```

### 代币流通

```
对于发币的项目：
- 团队和投资人通过代币变现
- 解锁后可在二级市场卖出
- 但受市场情绪影响巨大
```

## 给从业者的启示

### 创业者

```
关于融资：
- 选择适合你模式的策略（VC vs 代币 vs 自给）
- 不要被估值绑架（高估值有压力）
- 长期主义比短期估值重要

关于估值：
- 周期会变，但价值在于产品
- 不要为了估值做不该做的事
- 现金流比估值更可靠
```

### 投资人

```
评估钱包项目：
- 看团队（钱包是长跑）
- 看用户质量（不只是数量）
- 看商业模式（如何赚钱）
- 看护城河（信任、生态、技术）

警惕：
- 过度依赖代币的项目
- 没有清晰商业模式的项目
- 仅靠"基础设施"叙事的项目
```

## 小结

钱包项目的资本故事既有传统科技公司的特征，也有加密原生项目的独特性：

1. **估值波动大**：受加密市场和叙事影响
2. **多种融资路径**：VC 股权、代币、混合
3. **退出选项有限**：IPO 难，主要靠收购或代币
4. **长期主义胜出**：短期估值不重要，长期价值才是

未来 5 年，钱包赛道可能出现：
- 更多 IPO（成熟公司）
- 更多收购（大公司整合）
- 更多代币流通（社区项目）
- 估值整体趋于理性

资本市场对钱包的判断，最终会回归到"这是不是好生意"——而不是"这是不是好叙事"。
